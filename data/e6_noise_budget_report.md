## 2. 噪声模型

HEDGE 使用 **单素数 Q**，因此密文乘之后 **无法做 rescale**
（rescale 需要消耗一个素数因子）。这与多素数 CKKS 的关键区别决定了
噪声增长的上界。

在系数域（TRUE coefficient error，不含 QSCALE 除数）跟踪每步密文误差 (σ, M)：

```
明文乘 ct·pt (Dense):        v' = v · |p|
                               σ_out = ||w||_2·σ0 ,  M_out = ||w||_1·M0
密文乘 ct⊗ct (无 rescale):   v' = z_a·Δ·v_b + z_b·Δ·v_a + c·v_a·v_b
```
其中 z_a, z_b 为操作数消息的实数幅值（coeff 域消息 = z·Δ），
v_a, v_b 为系数域加性误差。最后换算到 real 域报告：
`max_noise = M/(Δ·QSCALE_k)`，与 paper_data_summary §4.2 同口径；
`noise_over_Q = M/Q`；`overflow_flag = (M > Q/2)`。

### 校准
用 paper_data_summary §4.2 的 L1 实测 (max=2.66e-6, mean=5.71e-7) 反推
fresh 加密误差，使 depth-1（ct×pt，对应 HEDGE 每层重新加密）L1 精确复现实测。
得到 σ0=5.6964e+04, M0=1.0276e+04（coeff 域）。

## 4. 噪声上限与 bootstrapping 触发点

- **精度触发深度 = 2**：real 域噪声超过分类所需精度 (~0.1)，
  密文推理结果已不可信。链式 ct⊗ct 在 depth 2 即破坏精度。
- **模数溢出 (Q/2) 触发深度 = 3**：系数域误差超过 Q/2，
  解密将产生回绕错误。此时必须触发 bootstrapping（或 modulus switching）。

**d=5 是否溢出 Q/2**：是（overflow_flag=1）。

## 5. 结论与设计含义

1. **单素数 + 无 rescale 是噪声爆炸的根因**：ct⊗ct 的误差项
   `z_b·Δ·v_a` 与 `c·v_a·v_b` 缺少 rescale 的 /Δ 衰减，
   使噪声随深度近似每步乘以 ~z·Δ（数千万量级），depth 3 即溢出 Q/2。
2. **HEDGE 的真实管线是安全的**：每层 Dense 用 ct×pt（明文权重），
   且在 ReLU 处 **重新加密**，使有效乘法深度恒为 1，噪声保持 ~1e-6
   （见 §2 校准表），远小于 Q/2 与分类所需精度。
3. **若要实现真正的 depth-d 密文电路**（如加密 ReLU 不重新加密），
   单一 47-bit 素数不足以支撑：depth 3 前必须引入 bootstrapping
   或多素数模数链（modulus switching）。当前 HEDGE 原型通过
   ct×pt + 重新加密规避了该问题，是一个合理的 secret-key 验证平台设计。
