# E10 端到端密文推理精度 + Bootstrap 置信区间

> HEDGE FPGA 项目 · 深圳职业技术大学 · 作者 Yi Haibo

> CKKS (N=8192, Q=47-bit, Δ=2^21) · 3 层 MLP (784→512→256→10, 536,714 参数)

> 权重 16-bit Q0.16 · 预缩放 S1=S2=4 · 私钥 CKKS 原型


## 1. 实验目的
端到端验证 HEDGE 密文推理在**更大样本**上的精度表现，并给出统计置信区间：
- 密文 Top-1（N 张）+ bootstrap 95% 置信区间（1000 次重采样）
- 明文 Top-1（**同一批 N 张样本**，apples-to-apples）+ 95% CI
- 密文-明文一致率（核心指标，预期 = 100%，证明加密未引入额外误差）
- 与明文全量 98.02% 对比，并做小样本偏差校正说明

## 2. 批量策略判定（先读实现）
读取 `hedge/cpu_proto/host/ckks_min.py` 与 `encrypted_infer.py` 后确认：
- 实现为 **single-slot CKKS**：每密文仅编码 1 个实数（slot 0）。
- `run_encrypted` 把一张图的 784 个像素各加密成独立密文（共 784 个），
  逐张走 `encrypt → dense → decrypt → ReLU → encrypt …` 完整流水线。
- 不存在跨图 batching（即把多张图打包进一个密文的 8192 slots 的 SIMD 编码）。
  代码注释亦明确：*“Functionally equivalent to multi-slot for accuracy; only
  throughput differs.”* —— 但本原型未实现 multi-slot。

**结论：无 batching，采用逐张（per-image）策略。** 单图密文推理耗时 
约 383 s（见 §6），故样本量受算力约束。

## 3. 样本与配置
| 项 | 值 |
|----|----|
| 样本量 N | **200 张** |
| 抽样方式 | 分层抽样（每类 20 张，取测试集每类前 20 张，确定可复现） |
| 随机种子 | seed=42（与 F11 扩展实验一致，便于对照） |
| 权重 | 16-bit 量化 (Q0.16) + scale=4 预缩放，与 F11 完全一致 |
| ReLU | 明文域精确 ReLU（上限精度，不含硬件 7.8e-3 逼近误差） |
| 明文参考 | 同一批 N 张，run_encrypted 内部 z3_pt（同权重同预缩放） |
| Bootstrap | 1000 次有放回重采样，2.5/97.5 分位为 95% CI |

## 4. 核心结果
| 指标 | 点估计 | 95% CI (bootstrap, N=1000) |
|------|--------|-----------------------------|
| 密文 Top-1 | **98.50%** | [96.50%, 100.00%] |
| 明文 Top-1（同 N 张） | **98.50%** | [96.50%, 100.00%] |
| 密文-明文一致率 | **100.00%** | [100.00%, 100.00%] |

> **一致率 = 100.00%** 是本实验最关键结论：密文与明文预测在所有 200 张上
> 完全一致，证明 CKKS 加密（噪声 ~3e-6，远低于分类所需 ~0.1 精度）
> 对 MNIST 推理精度的影响为零。任何密文分类错误都源自模型本身，而非加密。

## 5. 与明文全量 98.02% 的对比（小样本偏差校正）
- 明文全量基线（10000 张）：**98.02%**（paper_data_summary.md §4.1/§6.1）。
- 本实验同批样本明文 Top-1 = **98.50%**，与全量偏差 **0.48 pp**；
  密文 Top-1 = **98.50%**，偏差 **0.48 pp**。
- 偏差校正说明：
  1. 偏差本质为**抽样方差**而非加密误差——一致率 100% 已隔离加密因素；
  2. 全量 98.02% 是否落入样本 CI：明文 落入(一致)，密文 落入(一致)；
  3. 样本 Top-1 的 CI 半宽约 ±1.75 pp（明文）/ ±1.75 pp（密文），
    随 N 增大而收窄；N→10000 时即收敛到全量 98.02% 附近。
  4. 因此密文推理真实精度 = 明文模型精度（98.02%），加密零损失；
    小样本下的若干 pp 波动属正常统计噪声。

| 项 | 值 |

## 7. 结论
1. **密文-明文一致率 = 100.00%**：CKKS 加密对 HEDGE MNIST 推理精度影响为零。
2. **密文 Top-1 = 98.50%**（95% CI [96.50%, 100.00%]），与同批明文 Top-1 一致；
   与全量 98.02% 的偏差为小样本统计噪声，非加密引入。
3. 无 batching（single-slot CKKS），逐张推理；样本量受 ~383 s/张 限制，
   后续若实现 multi-slot SIMD 打包可线性提升吞吐、支撑更大样本。
4. 满足 F11 签核核心判据（密文-明文一致率 100%，加密未引入额外错误）。
